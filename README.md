# Онлайн уроки - платформа для онлайн-обучения

## Описание
Платформа для онлайн-обучения

## Запуск проекта с помощью Docker Compose
Этот проект использует Docker Compose для запуска всех необходимых сервисов одной командой. 

В состав проекта входят:

Веб-приложение на Django;

PostgreSQL — база данных;

Redis — брокер сообщений для Celery;

Celery Worker — для выполнения фоновых задач;

Celery Beat — для планирования периодических задач.

## Подготовка к запуску проекта:

Установите Docker.

Установите Docker Compose.

Убедитесь, что Docker запущен и работает.

Запустите Redis-server.exe

Запуск проекта

# Клонируйте репозиторий:
git clone https://github.com/Jylilapa/OnlineLessons

Создайте файл .env в корне проекта и добавьте туда необходимые переменные окружения, указанные в файле .env.sample.

Запустите проект, выполнив команду для запуска в фоновом режиме:

docker-compose up -d

После запуска push на GitHub запускается проверка flake8 и тесты. После успешного прохождения тестов проект автоматически копируется и развертывается на сервере
